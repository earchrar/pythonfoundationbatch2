=> Install Virtual Environment 

    # Ubuntu 
        sudo apt install python3-venv

    # Window 
        python3 -m venv ven 

=> Create Virtual Environment 

    # Linux / maxOs 
        python3 -m venu             # you can use anyname whatever you want "myenv"

    # Window 
        python -m venv myenv
        myenv\Scripts\activate
        (myenv) C:\Users\YourName\myproject>

    => for activate 
        #Linux/macOs 
        source myenv/bin/activate       // activate 

        # Window 
        .\myenv\Scripts\activate        // activate 

        pip3 list

        deactivate                     // deactivate 

        pip3 list

    => Create Database 
        Build > Firebase Database > Create Database 
        (i). Select edition > Standard edition > click "Next"
        (ii). Database ID & location 
            Database ID = (default) 
            Location = asia-southeast1 (Singapore) > click "Next"
        (iii). Configure > Start in production mode > click "create"

    => Error for writing (PERMISSION_DENIED) 
        Build > Firebase Database > Rules > allow read , write if true; > click "Publish"
